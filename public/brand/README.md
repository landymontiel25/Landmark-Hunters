# Brand assets for outside ratings

`tripadvisor-logo.svg` goes here: Tripadvisor's official "Ollie" logo (the
primary logo on light backgrounds), downloaded from
https://tripadvisor.mediaroom.com/logo-guidelines. Do not redraw or recolor
it. Until this file exists, the app hides every Tripadvisor rating, because
Tripadvisor's display rules require the logo beside the rating.
